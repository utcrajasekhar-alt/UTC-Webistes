# UTC — United Trading Company

A responsive corporate website built with React, TypeScript, Vite, Tailwind CSS, Lucide React, and Framer Motion.

## Requirements

- Node.js 18 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local development URL after startup.

## Production build

```bash
npm run build
npm run preview
```

The production files are written to `dist/`.

## Notes

- The hero, business-card, and Dubai building images load from Unsplash. Image containers have CSS fallbacks if remote images are unavailable.
- The map and market selector are illustrative and do not represent current UTC operations.
- The email address and phone/WhatsApp number displayed on the site were supplied for publication.
- No regulatory claims, financial results, or investment guarantees have been added.
- Google Fonts are loaded remotely; system sans-serif fallbacks remain available if they cannot load.
